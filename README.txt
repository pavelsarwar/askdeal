How to publish:
1. Upload all files and folders to your website public_html / www / hosting root.
2. Keep the assets folder in the same directory as index.html.
3. Open your domain. index.html will load automatically.

Notes:
- This is a front-end prototype using sample deal data in assets/app.js.
- Product search, price filters, sorting, drawer menu, and location permission are included.
- For real daily offers, merchant login, admin approval, database, and automatic location-based distance calculations, a backend/database will be required.

Expanded modules:

Important:
Live price/rate pages currently contain sample placeholders. Connect these pages to verified APIs,
