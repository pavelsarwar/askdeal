# NAPS

**Nationwide Affordable Price Search**

A Malaysia-focused prototype for discovering and comparing product prices, sales, promotions, events, gold/diamond information, remittance/exchange rates, fuel prices, tourism information, hospital comparison, how-to guides, and opportunities.

## Current status

- Static HTML/CSS/JavaScript prototype
- Popup disabled for now
- Product search and price filters included
- Product comparison included
- Sample data only for prices/rates that would require live sources in production
