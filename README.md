# Ask Deal

**Ask Deal for any Deal**

A Malaysia-focused deals discovery platform for finding nearby sales, promotions, clearance offers, freebies, promo codes, events and opportunities.

## Current focus

- Mobile-app-style PWA experience
- Nearby deal discovery using location permission
- Product and keyword search
- Price sorting and deal filters
- Clearance, Promotions, Freebies and Promo Codes
- Public deal submission with admin approval
- Dynamic offers and homepage content through Supabase
- Invite-based admin users

## Main pages

- Home
- Deals
- Product Comparison
- Categories
- Events & Fairs
- Travel Malaysia
- How To Guides
- Promo Codes
- Opportunities
- Submit Deal
- About
- Admin

## Stack

- HTML / CSS / JavaScript
- GitHub Pages
- Supabase
- PWA / Service Worker

The repository name remains `naps-malaysia` for compatibility with the current GitHub Pages URL, while the public product brand is **Ask Deal**.
